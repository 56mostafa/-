# مكتبة سياسة واقتصاد السويس — لوحة التحكم واستقبال ملفات الجهاز

## الملفات
- `index.html`: الموقع الذي يراه الطلاب.
- `admin.html`: لوحة التحكم لإدارة المواد والكتب وبيانات الموقع، واختيار ملفات PDF من الكمبيوتر أو الهاتف.
- `library-data.json`: بيانات الموقع الأساسية.

## اختيار ملفات من الجهاز
1. افتح `admin.html` على موقع المكتبة أو الاستضافة.
2. من «مواد الفرقة الأولى» أو «كتب الدراسات العليا»، املأ البيانات ثم اضغط اختيار ملف PDF من الجهاز.
3. اضغط حفظ/إضافة.
4. افتح «حفظ ونشر البيانات» ثم اختر «تنزيل حزمة البيانات وملفات PDF».
5. فك ضغط الحزمة على جهازك. ارفع `library-data.json` إلى جذر المستودع، وارفع ملفات PDF الموجودة داخل `files` إلى مجلد `files` في المستودع.
6. اضغط `Commit changes` وانتظر تحديث GitHub Pages.

## مهم
الاستضافة الحالية GitHub Pages ثابتة، لذلك لوحة التحكم تستقبل ملفات الجهاز وتجمعها في حزمة ZIP، لكنها لا تستطيع رفعها إلى GitHub مباشرة. الملفات المختارة تُحفظ في مخزن المتصفح على نفس الجهاز ما أمكن. لتحديث الموقع للطلاب، يلزم رفع الملفات الناتجة إلى المستودع. لا توجد قاعدة بيانات أو تسجيل دخول في هذه النسخة.
